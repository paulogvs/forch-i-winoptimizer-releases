# forch-i-winoptimizer-releases

Public release binaries for **FORCH.iA WinOptimizer**.

- The application source code lives in the **private** repo
  `paulogvs/forch-i-winoptimizer` (only the owner can read it).
- This repo contains **only** built artifacts (Setup/Portable `.exe`,
  `latest.yml`, `checksums.sha256`) attached to GitHub Releases.
- The in-app auto-updater (`electron-updater`) and the one-line installer
  read from here, so **no GitHub token is needed** on end-user PCs.
- Every binary is verifiable via `checksums.sha256` (SHA256).
